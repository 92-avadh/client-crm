# Retentio — Backend

This folder will contain the backend API server.

## Planned Stack (as per SRD Section 9)
- **Runtime:** Node.js (Express / Fastify) or Laravel / Django
- **Database:** PostgreSQL or MySQL
- **Cache / Queues:** Redis
- **Real-time:** Socket.io (WebSockets for chat)
- **Payments:** Razorpay Subscriptions API + Route (linked accounts)
- **Email:** SendGrid / AWS SES
- **Push:** Firebase Cloud Messaging (FCM)
- **Storage:** S3-compatible (AWS S3 / Cloudflare R2)
- **PDF Generation:** Puppeteer or PDFKit

## Planned Modules
- Authentication (JWT, OTP, sessions, 2FA)
- Subscription & Billing (Razorpay recurring)
- Brand / Client API
- Team & Assignment API
- Invoice & Payment API
- Expense API
- Chat API (WebSocket server)
- Notification Service (email, push, WhatsApp)
- Retention Scheduler (cron jobs)
- Reports & Export API
- Settings API
- Audit Log API
